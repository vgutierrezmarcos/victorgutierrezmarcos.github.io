% La industria naciente en equilibrio general (3 paneles, mismos ejes):
% X = el bien que se protege; Y = el otro. Preferencias U = XY (iguales en
% los 3 paneles: el consumo gasta la mitad de la renta en cada bien).
% FPP: (X/3)^2 + (Y/4)^2 = 1; RRI de libre comercio p = p_X/p_Y = 0,8.
%   Tangencia con la RRI: S = sqrt(a^2 p^2 + b^2), X = a^2 p/S, Y = b^2/S;
%   renta (en Y) = S; consumo X = S/(2p), Y = S/2.
% Izquierda (a = 3): S = 4,665; P_0 = (1,543; 3,430); C_0 = (2,916; 2,332);
%   U_0 = 6,80: importa X (C_0 a la derecha de P_0).
% Centro (arancel prohibitivo): autarquía A = (3/sqrt2; 4/sqrt2) =
%   (2,121; 2,828), U_A = 6,00 < U_0; más X producida que en P_0.
% Derecha (FPP' con a = 6, expandida hacia X; exporta porque a p > b):
%   S = 6,248; P_1 = (4,609; 2,561); C_1 = (3,905; 3,124); U_1 = 12,20 > U_0.
% Autor: Víctor Gutiérrez Marcos
