% Tarifa en dos partes con 2 tipos de consumidores (3.A.17, II.1.2, c).
% Demandas p = t_i (1 - q), es decir q_i(p) = 1 - p/t_i, con t_1 = 3 (tipo bajo)
% y t_2 = 6 (tipo alto); coste marginal c = 1,2; el mismo número de cada tipo.
%   i) Cuotas distintas: p = c, A_i = EC_i(c); q_1(c) = 0,6, q_2(c) = 0,8.
%   ii) Cuota común sin exclusión (Oi): A = EC_1(p) y
%       p - c = n_2 [q_2(p) - q_1(p)] / [n_1/t_1 + n_2/t_2] = (p/6)/(1/2) = p/3
%       -> p = 1,8 > c; q_1(p) = 0,4, q_2(p) = 0,7.
%   iii) Cuota que excluye al tipo bajo: p = c, A = EC_2(c).
% Colores (canon): lo que se apropia el monopolista en dorado; lo que se queda
% el consumidor (renta del tipo alto en ii) en morado; pérdida irrecuperable en
% rojo al 30 % (los 2 tipos en ii; el tipo bajo excluido en iii).
% Elaboración propia a partir de Oi (1971).
% Autor: Víctor Gutiérrez Marcos
