% Discriminación de tercer grado (3.A.17, II.1.3).
% Mercado 1: p_1 = 10 - 2 q_1, IMg_1 = 10 - 4 q_1 (demanda menos elástica).
% Mercado 2: p_2 = 6 - 0,5 q_2, IMg_2 = 6 - q_2 (demanda más elástica).
% IMg agregado (suma horizontal): q = (10 - m)/4 para m >= 6 (solo el mercado 1);
%   q = (10 - m)/4 + (6 - m) para m < 6, es decir m = 6,8 - 0,8 q (vértice en q = 1).
% CMg(q) = 1 + 0,5 q. Corte: 6,8 - 0,8 q = 1 + 0,5 q -> q = 4,4615, m = 3,2308.
%   q_1 = (10 - m)/4 = 1,6923, p_1 = 6,6154; q_2 = 6 - m = 2,7692, p_2 = 4,6154.
%   |eps_1| = p_1/(2 q_1) = 1,95 < |eps_2| = p_2/(0,5 q_2) = 3,33, y p_1 > p_2.
