% Curvas de coste unitario y Stolper-Samuelson (3.A.21, anexo E).
% Costes unitarios Cobb-Douglas: c_X = w_L^0,6 w_K^0,4 (X intensivo en trabajo) y
%   c_Y = w_L^0,4 w_K^0,6. Precios iniciales p_X = p_Y = 2: corte A = (2, 2).
% c_X = p_X: w_K = 5,657 w_L^-1,5; c_Y = p_Y: w_K = 3,175 w_L^-0,667.
% Pendientes en A (-a_Lj/a_Kj): -1,5 en X (más inclinada) y -0,667 en Y.
% Sube p_X a p'_X = 2,3 (+13,98 % en logaritmos): c_X = p'_X: w_K = 8,02 w_L^-1,5.
%   Nuevo corte B: ln w_L sube 3·0,1398 = 0,419 (w_L = 3,041) y ln w_K baja
%   2·0,1398 = 0,280 (w_K = 1,512): w_L sube más que p_X y w_K baja.
% Autor: Víctor Gutiérrez Marcos

  % 1: ejes
