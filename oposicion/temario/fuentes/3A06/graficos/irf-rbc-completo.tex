% Funciones impulso-respuesta del modelo de ciclo real a un shock de
% productividad de una desviación típica (eps^A_0 = sigma_eps = 0,007), en %
% de desviación del estado estacionario, t = 0 ... 40 trimestres (3.A.6, anexo D: los 7 paneles).
% Simulación propia: irf-rbc.py (en esta carpeta) escribe ../datos/irf-rbc.csv
% con la calibración de su cabecera (alfa = 1/3, beta = 0,99, delta = 0,025,
% phi = 1, L = 1/3, rho_A = 0,95, sigma_eps = 0,007; Prescott, 1986; Hansen y
% Wright, 1992). Continua: rho_A = 0,95; discontinua: rho_A = 0 (ruido blanco).
% r: rendimiento real del capital, en puntos porcentuales anualizados.
% Impacto con rho_A = 0,95: Y 0,92 %, C 0,27 %, I 2,99 %; con rho_A = 0: Y 1,02 %,
% C 0,06 %, I 4,10 %, y Y vuelve a 0,02 % al trimestre siguiente.
