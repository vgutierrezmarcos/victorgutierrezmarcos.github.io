% Persistencia en el modelo de McCallum (1989) (3.A.6, anexo D): respuesta de
% ln Y a un shock tecnológico de 1 en k = 0, con delta = 1, utilidad
% logarítmica, L = 1 y K_{t+1} = alpha beta A_t K_t^alpha (Y_t = A_t K_t^alpha).
% Solución cerrada: ln K_{t+1} = ln(alpha beta) + ln Y_t, luego la desviación de
% ln Y es y_k = a_k + alpha y_{k-1}:
%   rho_A = 0:   y_k = alpha^k = 1; 0,333; 0,111; 0,037; 0,012; ...  (alpha = 1/3)
%   rho_A = 0,95: y_k = (rho^{k+1} - alpha^{k+1})/(rho - alpha)
%               = 1; 1,283; 1,330; 1,301; 1,248; 1,190; 1,132; 1,076; 1,022
%   (rho_A = 0,95, como en el resto del tema)
% Sustituye a la imagen 6 del original (image21.jpg). Funciones, sin CSV; las
% 2 series se desplazan 0,13 a cada lado de k para que se vean las 2.
% Autor: Víctor Gutiérrez Marcos
