% Modelo neokeynesiano de una economía pequeña y abierta (Galí y Monacelli,
% 2005) en el plano (x_t, pi_{H,t}), con expectativas dadas (perturbaciones
% transitorias). Misma forma, valores y colores que nek-xpi, el gráfico de
% referencia de la ficha «nek-3-ecuaciones» (3.A.7): NKPC morada, DA verde.
%   NKPC: pi_H = kappa_alpha x + u, con kappa_alpha = 0,5
%   DA (IS dinámica + regla de Taylor): pi_H = -x + (r^n - rho - eps)/phi_pi
%   E_0 = (0, 0)
%   a) demanda: DA' pi = -x + 0,75; E_1 = (0,5; 0,25); si el banco central
%      sigue a r^n, la DA no se mueve: divina coincidencia (vuelta a E_0)
%   b) costes: NKPC' pi = 0,5 x + 0,5; E_1 = (-1/3; 1/3) con la regla;
%      E_pi = (-1; 0) (inflación en el objetivo, más recesión);
%      E_x = (0; 0,5) (brecha cerrada, más inflación)
%   c) política de oferta: NKPC'' pi = 0,5 x + 0,15; E_2 = (-0,1; 0,1)
