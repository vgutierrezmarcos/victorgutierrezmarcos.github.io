% El modelo neokeynesiano de pequeña economía abierta (Galí y Monacelli, 2005,
% con el gasto público de Furlanetto, 2006) en el plano (x_t, pi_{H,t}), con
% expectativas dadas (perturbaciones transitorias) y la regla de Taylor con la
% inflación interna (DITR). Mismos valores y colores que nek-perturbaciones
% (bloque II) y nek-xpi (3.A.7): NKPC morada, DA verde (18/11/2026).
%   Economía de partida: theta_aG = 1, phi_x = 0,5, phi_pi = 1,5, kappa_a = 0,5
%   NKPC: pi_H = 0,5 x;  DA: pi_H = -x + (r^n - rho - eps)/phi_pi
%   a) contracción monetaria (eps = 1,125): DA' pi_H = -x - 0,75;
%      E_1 = (-0,5; -0,25)
%   b) expansión fiscal: r^n sube; con la DITR, DA' pi_H = -x + 0,75,
%      E_1 = (0,5; 0,25); con tipo fijo (i_t no sube), DA'' pi_H = -x + 1,5,
%      E_2 = (1; 0,5); con la DIT, i_t sigue a r^n_t y vuelve a E_0
%   c) apertura con Theta > 0: theta_aG = 0,5 y, con varphi = 1 y
%      lambda = 0,25, kappa_a = 0,375. DA'_alpha pi_H = -(2/3) x - 0,75;
%      E_1^alpha = (-0,72; -0,27), frente a E_1 = (-0,5; -0,25) con alpha = 0
