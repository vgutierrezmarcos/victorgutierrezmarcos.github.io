% Rendimientos globales y locales a escala en tres dimensiones: solo las superficies
% (fila de arriba de rendimientos-globales-locales-3d), para el apoyo del vídeo del cante
% (tema 3.A.11). Capa 1: homogénea de grado 1; capa 2: tecnología «en S».
% Elaboración propia a partir de Fuleky (2006) y del ejemplo «en S» del tema.
%   (a) Homogénea de grado 1: q = (z_L z_K)^(1/2). Rayo z_K = z_L con zbar = (1,1):
%       F(lambda zbar) = lambda = lambda F(zbar): eps_{q,lambda} = 1 en todo punto.
%   (b) q = kappa/(1 + z_L^{-a} z_K^{-b}) con a = b = 1, kappa = 1: q = z_L z_K/(1 + z_L z_K),
%       meseta a la altura kappa. A lo largo del rayo, q(lambda) = lambda^2/(1+lambda^2), en S.
%       q/lambda = lambda/(1+lambda^2) es máximo en lambda* = 1 (q* = 1/2): el rayo desde el
%       origen q = lambda/2 es tangente allí (pendiente q'(1) = 1/2) y eps_{q,lambda} = 1;
%       eps = (a+b)(1 - q/kappa) = 2(1-q) > 1 si lambda < 1 y < 1 si lambda > 1.
% Vista por defecto de pgfplots (acimut 30°, elevación 28°): origen a la izquierda, q vertical,
% z_L a la derecha algo hacia abajo, z_K en profundidad. La superficie se parte por el plano
% vertical que contiene el rayo: mitad de detrás, rayo, plano (hasta el corte), mitad de
% delante y, encima, el corte.
