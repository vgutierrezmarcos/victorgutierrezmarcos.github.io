% Aumento de la tasa de ahorro en t_0 (como las figuras 1.5 y 1.6 de Romer, 2019).
% (a) plano (k, inversión), alfa = 1/2 en unidades del dibujo (como solow):
%     s_0 f(k) = 0,63 k^(1/2), s_1 f(k) = 0,85 k^(1/2), (n+g+delta) k = 0,38 k:
%     k*_0 = 2,7487; k*_1 = (0,85/0,38)^2 = 5,0035.
% (b)-(d) sendas temporales con la solución exacta (alfa = 1/3, n+g+delta = 0,1,
%     g = 0,02, s de 0,2 a 0,3): psi = k^(2/3) = 3 - e^(-tau/15);
%     k = psi^(3/2): 2,828 -> 5,196;  c = (1-s) psi^(1/2): 1,131 -> 0,990 -> 1,212;
%     gamma_{Y/L} = g + (1/3) gamma_k = g + 0,5 psi'/psi: 0,02 -> 0,0367 -> 0,02;
%     ln(Y/L) = ln A_0 + g tau + 0,5 ln psi: sube 0,5 ln(3/2) = 0,203 sobre la
%     senda antigua.
% Dibujo de las sendas: x = 1,2 + 0,095 tau (t_0 en x = 1,2); cada variable
% reescalada dentro de su panel (los ejes no empiezan en 0).
% Autor: Víctor Gutiérrez Marcos
