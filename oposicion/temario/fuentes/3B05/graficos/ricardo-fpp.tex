% Ventaja comparativa de Ricardo con los números de tab:pano-vino.
% A = Inglaterra, B = Portugal; X = paño (abscisas), Y = vino (ordenadas).
% L^A = L^B = 2.400 hombres-año; a_X^A = 100, a_Y^A = 120, a_X^B = 90, a_Y^B = 80.
%   FPP de A: de (24, 0) a (0, 20), pendiente -100/120 = -0,83.
%   FPP de B: de (26,7, 0) a (0, 30), pendiente -90/80 = -1,125.
%   RRI = p_X/p_Y = 1: A se especializa en P^A = (24, 0) y consume en X + Y = 24;
%   B se especializa en P^B = (0, 30) y consume en X + Y = 30.
%   Consumo (opcional): C^A = (14, 10) y C^B = (10, 20): A exporta 10 de paño,
%   que B importa; B exporta 10 de vino, que A importa (comercio equilibrado).
% Elaboración propia a partir de Krugman, Obstfeld y Melitz (2018), cap. 3.
% Autor: Víctor Gutiérrez Marcos
