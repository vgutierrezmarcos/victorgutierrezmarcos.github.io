% De Haberler a la curva de oferta neta de B, paso a paso (pareja de
% haberler-oferta-neta-a.tex). Es el país B de ofertas-netas.tex:
%   FPP X^2/9 + Y^2/144 = 1 (sesgada hacia Y); la misma CIS Cobb-Douglas
%   simétrica; (p_X/p_Y)^B_aut = 4, E^B_aut = (2,121; 8,485), CIS_0: XY = 18.
%   Con RRI = p, d = sqrt(p^2 + 16): P = (3p/d, 48/d); renta 3d (en Y);
%   C = (3d/(2p), 3d/2). Importa X_C - X_P = 3d/(2p) - 3p/d de X y exporta
%   Y_P - Y_C = 48/d - 3d/2 de Y.
%   p = 3: P = (1,8; 9,6), C = (2,5; 7,5): importa 0,7 de X, exporta 2,1 de Y.
%   p = 2: P = (1,342; 10,733), C = (3,354; 6,708): importa 2,012, exporta
%          4,025 (justo lo que A quiere vender y comprar con p = 2).
%   En el plano del comercio, abscisas = X (lo que B importa), ordenadas = Y
%   (lo que B exporta): los mismos ejes que ON_A, para poder juntarlas.
% Elaboración propia a partir de Haberler (1936), Marshall (1879) y Gandolfo
% (2014), cap. 3.
% Autor: Víctor Gutiérrez Marcos
