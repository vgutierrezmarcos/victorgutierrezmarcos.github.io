% Geometría de los costes y curva de oferta con un solo producto: seis casos.
% Elaboración propia a partir de Mas-Colell, Whinston y Green (1995, §5.D,
% figuras 5.D.1 a 5.D.6). Cada caso tiene dos pisos: arriba, la tecnología
% con un solo factor z (función de producción q = F(z) y conjunto de
% producción 𝒴 sombreado, en el plano (z, q)); abajo, sus costes medios y
% marginales y la oferta (resaltada en rojo translúcido). Con el precio del
% factor normalizado, w = 1, el coste de producir q es el factor que hace
% falta: C(q) = z(q) = F^{-1}(q) (más el factor fijo, si lo hay), de modo que
% el CMe es la inversa del producto medio (q/z) y el CMg, la del marginal.
% (1) C = 0,75 q^1,6: F(z) = (z/0,75)^0,625, cóncava (rendimientos
%     decrecientes); CMe = 0,75 q^0,6, CMg = 1,2 q^0,6 (ambos desde 0).
% (2) C = c q, c = 1,3: F(z) = z/c, lineal; CMe = CMg = c.
% (3) C = 2 q - 1,2 q^2 + 0,3 q^3 (C' > 0): F = C^{-1}, convexa y después
%     cóncava; CMe = 2 - 1,2 q + 0,3 q^2 (mínimo en q = 2, CMe = 0,8),
%     CMg = 2 - 2,4 q + 0,9 q^2 (CMg(2) = 0,8). En q = 2 (z = 1,6) el rayo
%     desde el origen es tangente a F: producto medio máximo, 2/1,6 = 1/0,8.
% (4) C = 1,6 + 0,4 q^2 si q > 0 y C(0) = 0 (coste fijo evitable): hace
%     falta un factor de puesta en marcha z_F = 1,6 antes de producir,
%     F(z) = ((z - 1,6)/0,4)^{1/2} para z >= 1,6 y q = 0 (inacción) con
%     z < 1,6; CMe = 1,6/q + 0,4 q (mínimo en q = 2, CMe = 1,6), CMg = 0,8 q.
%     El rayo desde el origen es tangente a F en (3,2; 2): 2/3,2 = 1/1,6.
% (5) C = 1 + 0,9 q si q > 0: z_F = 1, F(z) = (z - 1)/0,9 para z >= 1;
%     CMe = 0,9 + 1/q, CMg = c = 0,9. El producto medio crece sin cesar
%     hacia 1/c: no hay tangencia.
% (6) C = 0,8 + 1,4 q - 0,6 q^2 + 0,15 q^3 con el 0,8 hundido: el factor
%     fijo z_F = 0,8 se usa siempre (los puntos con z < 0,8 no están en 𝒴),
%     F(z) = C_v^{-1}(z - 0,8) con C_v = 1,4 q - 0,6 q^2 + 0,15 q^3;
%     CVMe = 1,4 - 0,6 q + 0,15 q^2 (mínimo en q = 2, CVMe = 0,8),
%     CMg = 1,4 - 1,2 q + 0,45 q^2, CMe = CVMe + 0,8/q (mínimo en
%     q = 2,446, CMe = 1,157). El rayo desde (z_F, 0) es tangente a F en
%     (2,4; 2): 2/1,6 = 1/CVMe(2). MWG usa aquí costes variables
%     estrictamente convexos (CVMe mínimo en q = 0); se dibuja el CVMe en U
%     para que se vea el mínimo de explotación del texto.
% Escalas: abajo, q y €/u a 1 cm; arriba, q a 0,85 cm y z a la escala de cada
% caso para que quepa en el mismo ancho.
% Autor: Víctor Gutiérrez Marcos
