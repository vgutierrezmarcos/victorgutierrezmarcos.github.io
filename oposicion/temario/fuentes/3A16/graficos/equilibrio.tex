% Oferta de mercado (suma horizontal de las ofertas) y equilibrio competitivo.
% Izquierda: 2 empresas con costes estrictamente convexos y C_j(0) = 0:
%   CMg_1(q) = 0,5 + q    ->  q_1(p) = p - 0,5        (p >= 0,5)
%   CMg_2(q) = 1 + 1,5 q  ->  q_2(p) = (p - 1)/1,5    (p >= 1)
%   q(p) = q_1 + q_2: p^S(q) = q + 0,5 si q <= 0,5 y p^S(q) = 0,6 q + 0,7 después.
%   A p̄ = 2,8: q_1 = 2,3; q_2 = 1,2; q = 3,5.
% Derecha: la oferta de la izquierda y la demanda de mercado de agregacion-demanda.tex:
%   p^D(x) = 3 - 1,5 x si x <= 2/3 y p^D(x) = (4,5 - x)/1,9167 después.
%   Corte: 0,6 q + 0,7 = (4,5 - q)/1,9167 -> q* = x* = 1,469; p* = 1,581.
