% Equilibrio con controles de precios (anexo C): manda el lado corto.
% Mismas curvas que excedentes: demanda inversa p^D(x) = 4,2 - 0,6 x;
% oferta inversa p^S(q) = 0,6 + 0,9 q; equilibrio x* = q* = 2,4 y p* = 2,76.
% Precio máximo p^max = 2: q(p^max) = 1,4/0,9 = 1,556 < x(p^max) = 2,2/0,6 = 3,667
%   (exceso de demanda); se intercambia q(p^max); pérdida: triángulo de vértices
%   (1,556; p^D = 3,267), (1,556; p^S = 2) y E.
% Precio mínimo p^min = 3,4: x(p^min) = 0,8/0,6 = 1,333 < q(p^min) = 2,8/0,9 = 3,111
%   (exceso de oferta); se intercambia x(p^min); pérdida: triángulo de vértices
%   (1,333; p^D = 3,4), (1,333; p^S = 1,8) y E.
% Corrección respecto al original (ICEX-CECO, fig. 21): allí el punto sobre la
% demanda con p mínimo aparece rotulado q(p̄); aquí, x(p^min).
