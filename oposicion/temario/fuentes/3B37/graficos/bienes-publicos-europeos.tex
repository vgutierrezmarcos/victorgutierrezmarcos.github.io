% Bienes públicos europeos (Samuelson, 1954; Bowen, 1943) con N = 3 Estados
% iguales: beneficio marginal de cada Estado BMg_i(G) = 0,5 (8 - G) y suma
% vertical sum BMg_i = 1,5 (8 - G); coste marginal constante c = 2.
% Provisión nacional (Nash): BMg_i = c -> G^N = 4. Provisión europea
% (Samuelson): sum BMg_i = c -> G* = 8 - 2/1,5 = 6,67. Pérdida: triángulo
% (4,2)-(4,6)-(6,67,2). Escala: x 1 = 0,8 cm; y 1 = 0,45 cm.
% Capas: ejes -> coste marginal -> BMg de un Estado y G^N -> suma vertical
% y G* -> pérdida de bienestar.
% Autor: Víctor Gutiérrez Marcos

  % 2: coste marginal
  \capa{2}{\draw[curva4] (0,2) -- (9.2,2) node[right,etiqueta] {$c$};}
