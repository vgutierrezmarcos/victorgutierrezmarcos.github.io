% El coste medio a largo plazo como envolvente de los costes medios a corto
% plazo (y el error de Viner). Elaboración propia a partir de Viner (1931) y
% Varian (1992, cap. 5).
% Largo plazo: CMe_LP(q) = 3 + 0,25 (q - 5)^2 (mínimo en q = 5, valor 3);
%   C_LP(q) = q CMe_LP(q), CMg_LP(q) = CMe_LP(q) + 0,5 q (q - 5).
% Corto plazo, planta i (óptima para q_i = 2,5; 5; 7,5):
%   C_i(q) = C_LP(q) + 1,5 (q - q_i)^2 >= C_LP(q), tangentes en q_i
%   (coste fijo 1,5 q_i^2), de modo que
%   CMe_i(q) = CMe_LP(q) + 1,5 (q - q_i)^2 / q   (tangente a CMe_LP en q_i),
%   CMg_i(q) = CMg_LP(q) + 3 (q - q_i)            (corta a CMg_LP en q_i y es más
%                                                  inclinado: Le Châtelier-Samuelson).
%   Mínimos: planta 1 en q = 3,52 (3,99), a la derecha de la tangencia (2,5; 4,56);
%            planta 3 en q = 6,28 (3,77), a la izquierda de la tangencia (7,5; 4,56);
%            planta 2 en q = 5, sobre el mínimo del CMe_LP (5; 3).
% q a 0,9 cm por unidad; euros a 0,6 cm por unidad.
% Autor: Víctor Gutiérrez Marcos
