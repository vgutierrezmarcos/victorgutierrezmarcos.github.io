% Los costes a largo plazo como envolvente de los de corto plazo (y el error
% de Viner), en dos paneles alineados con el mismo eje q: arriba, los costes
% totales; abajo, los costes medios y marginales. Elaboración propia a partir
% de Viner (1931) y Varian (1992, cap. 5); recupera el panel de costes totales
% del gráfico del tema antiguo (Imagen 12).
% Largo plazo: C_LP(q) = G(q) = 3q + 0,15 q (q - 5)^2, en S (inflexión en
%   q = 10/3), CMe_LP(q) = 3 + 0,15 (q - 5)^2 (mínimo en q = 5, valor 3) y
%   CMg_LP(q) = G'(q) = 3 + 0,15 (q - 5)^2 + 0,3 q (q - 5).
% Corto plazo, planta i con el factor fijo óptimo para q_i = 2,2; 5; 7,8
%   (G_i = G(q_i) = 9,187; 15; 32,573), con la tecnología
%   C(q, K) = K + V(q) K^{-3} (K fijo a corto plazo):
%   C_i(q) = (G_i/4) [3 + (G(q)/G_i)^4] >= G(q), igual y tangente en q_i,
%   con coste fijo C_i(0) = 3 G_i/4 > 0 y coste variable creciente; así
%   CMe_i = C_i/q es tangente a CMe_LP en q_i y
%   CMg_i(q) = G'(q) (G(q)/G_i)^3 corta a CMg_LP en q_i con más pendiente
%   (Le Châtelier-Samuelson).
%   Mínimos del CMe a corto: planta 1 en q = 3,53 (3,68), a la derecha de la
%   tangencia (2,2; 4,18); planta 3 en q = 7,06 (3,91), a la izquierda de la
%   tangencia (7,8; 4,18); planta 2 en q = 5, sobre el mínimo del CMe_LP (5; 3).
% q a 0,9 cm por unidad; abajo, euros por unidad a 0,6 cm; arriba (desplazado
% 6,3 cm), euros a 0,085 cm.
% Autor: Víctor Gutiérrez Marcos
