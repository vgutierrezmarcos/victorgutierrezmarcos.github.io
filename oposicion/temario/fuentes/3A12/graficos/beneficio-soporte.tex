% La función de beneficio como función soporte del conjunto de posibilidades
% de producción (un factor). Frontera q = F(z) = 1,9 sqrt(z).
% Isobeneficio q = B/p + (w/p) z tangentes a la frontera:
%   (p',w'):   z' = 0,6, w'/p' = 1,2265, q' = 1,472, B'/p' = 0,736.
%   (p'',w''): z'' = 5,  w''/p'' = 0,4249, q'' = 4,249, B''/p'' = 2,124.
% (la ordenada en el origen de cada isobeneficio es B/p = F(z) - F'(z) z = F(z)/2).
% Autor: Víctor Gutiérrez Marcos
