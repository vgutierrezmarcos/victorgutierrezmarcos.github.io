% Mundell-Fleming con tipo flexible y movilidad perfecta: el mismo impulso en A
% según su tamaño (anexo de escenarios del 3.B.19). Arriba, expansión monetaria;

% Rectas; A = (3; 2,5); IS: Y = 5,5 - i; LM: i = 2,5 + 0,8 (Y - 3).
%   Monetaria: LM': i = 1,8 + 0,8 (Y - 4,2) = 0,8 Y - 1,56.
%     pequeño: i* = 2,5; IS'' Y = 7,575 - i; C = (5,075; 2,5)  -> dY = 2,075
%     grande:  i*' = 1,8; IS' Y = 6 - i;     C = (4,2; 1,8)     -> dY = 1,2
%     cerrada: IS no se mueve; C = IS y LM' = (3,922; 1,578)    -> dY = 0,922
%   Fiscal: IS' (gasto): Y = 7,6 - i.
%     pequeño: i* = 2,5; la apreciación devuelve la IS: C = A    -> dY = 0
%     grande:  i*' = 3,0; IS'' Y = 6,625 - i; C = (3,625; 3,0)  -> dY = 0,625
%     cerrada: C = IS' y LM = (4,167; 3,433)                    -> dY = 1,167
