% Corsetti y Pesenti (2005, 2009): el modelo de 2 países en el plano (l, C) y
% los efectos internacionales de la estabilización en A con fijación de precios
% en la moneda del productor (PCP, traspaso completo). Código de colores del
% artículo: negro, lo inicial; azul, lo exógeno (Z, mu); rojo, lo endógeno
% (P, tau, C).
%   Inicial en los 2 países: O = (3; 2), AS C = Z l tau = (2/3) l, AD C = 2, NR 3.
%   A: (1) Z sube: AS' C = l (con precios rígidos, A iría a (2; 2)).
%      (2) el banco central de A sube mu: deprecia (E = mu/mu* sube).
%      (3) con PCP, los bienes de A se abaratan fuera: tau baja, AS'' C = 0,85 l;
%      las importaciones se encarecen: P sube algo y la AD sube a 2,55.
%      H = (3; 2,55), sobre la NR: la brecha se cierra.
%   B: (4) mejora su relación de intercambio: tau_B sube, AS_B' C = 0,85 l;
%      (5) sus importaciones se abaratan: P_B baja, AD_B' C = 2,55.
%      H_B = (3; 2,55): más consumo con el mismo empleo (desbordamiento positivo).
% Capas: 1 ejes; 2 curvas iniciales (el modelo de 2 países: paso 1 en
% cp-pcp-paso1); 3-5 país A; 6-7 país B.
% Autor: Víctor Gutiérrez Marcos
