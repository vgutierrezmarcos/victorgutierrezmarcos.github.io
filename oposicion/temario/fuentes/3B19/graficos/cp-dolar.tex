% Corsetti y Pesenti (2005, 2009) con facturación en dólares (dollar pricing,
% traspaso asimétrico): todo el comercio se factura en la moneda de B (Estados
% Unidos). B sufre una subida de productividad y la estabiliza con una expansión
% monetaria. Código de colores del artículo: negro, lo inicial; azul, lo
% exógeno (Z, mu); rojo, lo endógeno (P, C, l).
%   a) B, el emisor: O_B = (3; 2), AS_B C = (2/3) l. (1) Z_B sube: AS_B' C = l.
%      (2) mu_B sube: sus precios de importación, en dólares, no se mueven:
%      la AD_B sube tanto como mu_B, C = 3, y tau_B no cambia: D_B = (3; 3), sobre
%      su NR. B se comporta como una economía cerrada.
%   b) A, el que no emite: O = (3; 2). (3) el dólar se deprecia y lo que A
%      importa se abarata en euros: P baja, AD' C = 2,55. La AS no gira (sus
%      exportaciones también están fijas en dólares): D = (3,825; 2,55), a la
%      derecha de su NR. H = (3; 2,55), el punto con PCP (AS C = 0,85 l), en gris
%      para comparar: consume lo mismo, pero trabaja más.
% Autor: Víctor Gutiérrez Marcos
