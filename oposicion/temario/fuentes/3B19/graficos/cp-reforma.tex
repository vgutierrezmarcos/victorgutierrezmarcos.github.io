% Corsetti y Pesenti (2005, 2009): reforma estructural en A que reduce el poder
% de mercado (sigma sube). Código de colores del artículo: negro, lo inicial;
% azul, lo exógeno (sigma); rojo, lo endógeno (tau, P, C, l).
%   a) A: O = (3; 2), AS C = (2/3) l. (1) sigma sube: NR -> l-barra' = 3,6
%      (NR = (sigma-1)/(sigma chi) crece con sigma). (2) A produce más y sus bienes
%      se abaratan: tau baja, AS' C = 0,6 l. (3) la AD sube a 2,16:
%      O' = (3,6; 2,16): A trabaja y consume más.
%   b) B: NR_B igual. (4) tau_B sube: AS_B' C = 0,75 l. (5) bajan sus precios
%      de importación: AD_B' C = 2,25: O_B' = (3; 2,25), más consumo con el
%      mismo trabajo.
