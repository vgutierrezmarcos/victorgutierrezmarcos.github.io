% Arancel en un país pequeño (equilibrio parcial), 3.B.7, I.2.1.
% Ejemplo del acero del texto: demanda x = 100 - p, oferta nacional q = p,
% p^W = 20, t = 50 %: p^W(1+t) = 30. Autarquía: p = 50 (arancel prohibitivo
% del 150 %).
% Libre comercio: q^0 = 20, x^0 = 80, M^0 = 60. Con el arancel: q^1 = 30,
% x^1 = 70, M^1 = 40.
% a = 250 (excedente del productor), b = 50 y d = 50 (distorsiones en la
% producción y en el consumo), c = 400 (recaudación); el consumidor pierde
% a + b + c + d = 750.
% Elaboración propia a partir de Feenstra y Taylor (2021), cap. 8, y Krugman,
% Obstfeld y Melitz (2018), cap. 9.
% Autor: Víctor Gutiérrez Marcos

  % 5: precio con arancel, cantidades nuevas y sus importaciones
