% El monopolio nacional en autarquía, con libre comercio y con arancel
% (3.B.7, anexo D). Mismas curvas que cuota-monopolio (acero):
%   demanda x = 100 - p; IMg = 100 - 2q; CMg = q de la única empresa nacional.
%   (1) Autarquía: IMg = CMg -> q^M = 33,3, p^M = 66,7; competencia (D = CMg):
%       q^c = p^c = 50; pérdida del monopolio: (66,7 - 33,3)(50 - 33,3)/2 = 278.
%   (2) Libre comercio, p^W = 20: demanda horizontal a 20 hasta x = 80;
%       CMg = 20 -> produce 20; importaciones 60.
%   (3) Arancel del 50 %: precio 30, produce 30, importaciones 40. Un arancel
%       mayor con p^c <= p^W(1+t) < p^M, p. ej. precio 55: abastece toda la
%       demanda, x(55) = 45 (CMg(45) = 45 < 55), sin importaciones.
% Estética del monopolio de 3A17 (equilibrio-monopolio).
% Elaboración propia a partir de Feenstra y Taylor (2021, cap. 9).
% Autor: Víctor Gutiérrez Marcos
