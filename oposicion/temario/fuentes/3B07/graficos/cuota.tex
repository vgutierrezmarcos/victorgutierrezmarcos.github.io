% Cuota a la importación y arancel equivalente en un país pequeño (3.B.7, II.1).
% Mismas curvas y escala que arancel-pequeno, con las cifras del acero:
%   demanda x = 100 - p; oferta nacional q = p; p^W = 20.
%   Libre comercio: q^0 = 20, x^0 = 80, M^0 = 60.
%   Cuota \bar M = 40: oferta S + \bar M, q = p + 40 (para p >= p^W), que corta
%   a D en p = 30 = p^W(1+t) con t = 50 %: q^1 = 30, x^1 = 70.
%   a = 250; b = 50; c = renta de la cuota = 400; d = 50 (b + d = 100).
% Áreas, con los colores de arancel-pequeno: a, excedente del productor
% (dorado); c, renta de la cuota (verde, la recaudación del arancel); b y d, PIE (rojo).
% Elaboración propia a partir de Feenstra y Taylor (2021, cap. 8).
% Autor: Víctor Gutiérrez Marcos
