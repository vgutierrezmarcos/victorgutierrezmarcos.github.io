% Cuota con un monopolio nacional (3.B.7, II.1): el monopolista de la demanda
% residual. Misma escala y curvas que cuota y arancel-pequeno (acero):
%   demanda x = 100 - p; CMg = q de la única empresa nacional; p^W = 20.
%   Cuota \bar M = 40: demanda residual x - \bar M = 60 - p; IMg_r = 60 - 2q.
%   IMg_r = CMg: 60 - 2q = q -> q = 20 (CMg = 20 = p^W); precio 60 - 20 = 40;
%   consumo x(40) = 60 = 20 + 40.
%   Arancel equivalente (50 %): precio 30, producción competitiva 30.
% Estética del monopolio de 3A17 (equilibrio-monopolio).
% Elaboración propia a partir de Bhagwati (1965) y Feenstra y Taylor (2021, cap. 9).
% Autor: Víctor Gutiérrez Marcos
