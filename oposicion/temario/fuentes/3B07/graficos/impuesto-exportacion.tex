% Impuesto a la exportación en un país pequeño (3.B.7, II.3).
% El de subvencion al revés: mismas curvas y escala (x = 100 - p, q = p).
% Cifras orientativas: p^W = 70; precio interior p^W/(1+t) = 60 (t = 1/6).
%   Libre comercio: x^0 = 30, q^0 = 70, X^0 = 40.
%   Con el impuesto: x^1 = 40, q^1 = 60, X^1 = 20.
%   a = 350 (trapecio de 0 a la demanda); b = 50; c = 10 x 20 = 200
%   (recaudación, de x^1 a q^1); d = 50. Productores: -(a+b+c+d) = -650 (el
%   trapecio entre los 2 precios a la izquierda de S); PIE: b+d = 100.
% Colores de arancel-pequeno: c, recaudación (verde); b y d, PIE (rojo); a,
% ganancia de los consumidores (morado, el excedente del consumidor de 3A16).
% Elaboración propia a partir de Feenstra y Taylor (2021, cap. 10).
% Autor: Víctor Gutiérrez Marcos
