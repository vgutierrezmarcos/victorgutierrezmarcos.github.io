% Protección de la propiedad intelectual entre el Norte y el Sur, en el
% espíritu de Grossman y Lai (2004), con el ejemplo lineal-cuadrático del tema:
%   W_S = L_S n (v - (b+d) T_S),  W_N = L_N n (v - (b+d) T_N) + kappa b^2 Tbar^2 / 2,
%   n = kappa b Tbar,  Tbar = L_N T_N + L_S T_S.
% Valores: v = b = 1, d = 0,5, L_N = L_S = 1, kappa = 1.
%   Mejor respuesta del Sur:   T_S = (1 - 1,5 T_N)/3   -> de (0, 1/3) a (2/3, 0)
%   Mejor respuesta del Norte: T_N = (1 - 0,5 T_S)/2   -> de (0,5, 0) a (0,25, 1)
%   Equilibrio de Nash E = (10/21, 2/21) = (0,476; 0,095); Tbar = 4/7 = 0,57
%   Óptimo mundial: Tbar* = v (L_N + L_S)/(b + 2d) = 1 -> recta T_N + T_S = 1
%   Armonización H = (0,5; 0,5): W_S 0,49 -> 0,25; W_N 0,33 -> 0,75
%   El Norte carga con la subida, A = (19/21, 2/21) = (0,905; 0,095)
% Capas: ejes -> mejor respuesta del Norte -> del Sur y equilibrio de Nash ->
% recta de protección eficiente -> armonización (H) y alternativa (A).
% Autor: Víctor Gutiérrez Marcos
