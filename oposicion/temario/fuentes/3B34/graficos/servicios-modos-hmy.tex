% Modos de suministro de servicios con costes fijos regulatorios: el modelo de
% Helpman, Melitz y Yeaple (2004) aplicado a los servicios (modo 1, suministro
% transfronterizo, frente a modo 3, presencia comercial). Mismas letras y
% estilos que melitz-umbrales (3.B.6) y hmy (3.B.18). Rectas en
% u = phi^(sigma-1) (cualitativas, países simétricos; wF^d = 1,
% wF^M1 = 1,4, wF^M3 = 2,2):
%   B^d  = 0,4 u - 1    -> (phi*)^(sigma-1)    = 2,5
%   B^M1 = 0,3 u - 1,4  -> (phi*_M1)^(sigma-1) = 4,667 (pendiente tau^(1-sigma)
%                          = 0,75 la del modo 3)
%   B^M3 = 0,4 u - 2,2  -> corta a B^M1 en u = 8 (B = 1): (phi*_M3)^(sigma-1) = 8
% Liberalizar el modo 3 (compromiso de acceso a los mercados): R^M3 baja y
% wF^M3' = 1,9: B^M3' = 0,4 u - 1,9 corta a B^M1 en u = 5 (B = 0,1).
% Condición de ordenación: F^M3 > tau^(sigma-1) F^M1 > F^d
%   (2,2 > 1,4/0,75 = 1,867 > 1; tras la rebaja, 1,9 > 1,867).
% Elaboración propia a partir de Helpman, Melitz y Yeaple (2004) y Kox y
% Nordås (2007).
% Autor: Víctor Gutiérrez Marcos
