% Respuestas a un aumento del gasto público del 1 % del PIB de estado
% estacionario en t = 0 en el modelo de ciclo real (Baxter y King, 1993),
% t = 0 ... 40 trimestres (3.A.38, I.2 b) iii), fig:irf-rbc-gasto).
% Simulación propia: irf-rbc-gasto.py (en esta carpeta) escribe
% ../datos/irf-rbc-gasto.csv con la calibración de su cabecera (alfa = 1/3,
% beta = 0,99, delta = 0,025, phi = 1, G/Y = 0,2; Prescott, 1986; Hansen y
% Wright, 1992). Mismo estilo y paleta que irf-rbc.tex del 3.A.6 y el 3.A.42
% (Y morado, C azul, I verde, L naranja, w rojo; la perturbación, G, en gris).
% (a) Suma fija: Y, C, I en puntos del PIB (multiplicadores); continua
%     rho_G = 0,95, discontinua rho_G = 0; G en gris fino.
% (b) Horas L y salario real w, en %, rho_G = 0,95.
% (c) Y con suma fija frente a Y con impuesto sobre el trabajo (presupuesto
%     equilibrado cada periodo), rho_G = 0,95.
% Impactos: Y 0,32 / 0,03 / -0,68; C -0,36 / -0,04 / -0,61;
% I -0,31 / -0,93 / -1,07; L 0,49; w -0,16.
% Autor: Víctor Gutiérrez Marcos

    dicapas},
}
