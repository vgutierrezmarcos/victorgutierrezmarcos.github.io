% Modelo de Gordon-Schaefer (apartado III.1.3). Parámetros normalizados:
% crecimiento logístico G(X) = gamma X (1 - X/Xbar) con gamma = 1, Xbar = 1;
% captura H = theta E X con theta = 1; precio p = 1; coste por unidad de
% esfuerzo c = 0,3.
%   Estado estacionario: X(E) = Xbar (1 - theta E/gamma) = 1 - E.
%   Captura sostenible: Y(E) = theta Xbar E (1 - theta E/gamma) = E (1 - E).
%   RMS: E = 0,5, X = 0,5, Y = 0,25.
%   Libre acceso (renta nula): Y(E) = 0,3 E -> E = 0,7, X = 0,3, Y = 0,21.
%   MRE: p Y'(E) = c -> 1 - 2E = 0,3 -> E = 0,35 (= E_LA/2), X = 0,65,
%        Y = 0,2275; renta = 0,2275 - 0,105 = 0,1225.
% Izquierda: plano (X, G): crecimiento y rectas de captura de los 3 esfuerzos.
% Derecha: plano (E, ingreso y coste): ingreso sostenible y coste total.
% Capas: ejes y crecimiento -> RMS -> libre acceso -> MRE (en los 2 paneles).
% Autor: Víctor Gutiérrez Marcos
