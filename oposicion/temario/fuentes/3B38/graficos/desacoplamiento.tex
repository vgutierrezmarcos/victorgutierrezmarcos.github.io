% Ayuda acoplada frente a ayuda desacoplada (modelo del apartado II.1.2).
% País pequeño: la producción se vende al precio mundial p^W = 3.
% Oferta inversa p^S(q) = 0,5 + 0,5 q, de modo que q_0 = 5.
% Izquierda: pago acoplado s = 1 por unidad: el productor recibe p^W + s = 4
%   y produce q_1 = 7. Coste presupuestario s q_1 = 7; ganancia del productor
%   (trapecio 0..7 entre 3 y 4) = 6; pérdida irrecuperable = triángulo de
%   producción (5,3)-(7,4)-(7,3), área 1. Eficiencia de la transferencia 6/7.
% Derecha: pago desacoplado de la misma cuantía (7), por hectárea o por
%   referencia histórica: no cambia el precio marginal, q = q_0; sin pérdida.
%   En la práctica, el desacoplamiento es imperfecto (efectos riqueza y
%   seguro, exigencia de mantener la tierra): la oferta se desplaza algo a la
%   derecha (línea discontinua «con el pago», desplazamiento ilustrativo de 0,6;
%   sin símbolo, para no confundirla con la pendiente q'(p) de la fórmula).
% Capas: ejes -> oferta y precio mundial -> pago acoplado -> pérdida ->
% panel derecho -> desacoplamiento imperfecto.
% Autor: Víctor Gutiérrez Marcos
