% Falvey (1981): comercio intraindustrial vertical con competencia perfecta.
% Coste unitario (= precio) de la calidad alpha en cada país: una unidad de
% trabajo y alpha unidades de capital, p_i(alpha) = w_i + alpha r_i, con r la
% renta del capital (no el tipo de interés).

%   w_A = 2, r_A = 0,5; w_B = 0,8, r_B = 1,2
%   alpha_0 = (w_A - w_B)/(r_B - r_A) = 1,2/0,7 = 12/7 (1,714); p = 2 + 6/7
